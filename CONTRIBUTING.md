# Contributing

Thanks for contributing.

## Quick checklist

- Keep changes focused and small.
- Preserve the extension's current behavior unless intentionally changing it.
- Test manually by loading the extension in `chrome://extensions` and verifying popup flow.
- Update `README.md` when user-facing behavior changes.

## Local test flow

1. Reload the unpacked extension in Chrome.
2. Visit a Twitch channel page and open the popup.
3. Confirm the detected channel shortcut appears.
4. Confirm manual input opens the embedded player tab.
